# Cybersecurity Lab

A collection of practical cybersecurity lab reports covering network reconnaissance, port scanning, vulnerability assessment, and phishing simulation using industry-standard tools on Kali Linux.

## Lab Reports

| # | Topic | Tools |
|---|-------|-------|
| 1 | [Network Reconnaissance](reports/01-network-reconnaissance/README.md) | Nmap |
| 2 | [Port Scanning](reports/02-port-scanning/README.md) | Nmap, RustScan |
| 3 | [Vulnerability Assessment](reports/03-vulnerability-assessment/README.md) | SQLMap, WPScan |
| 4 | [Phishing Simulation](reports/04-phishing-simulation/README.md) | GoPhish, SET |

## Environment

All labs were performed in a controlled, isolated lab environment using **Kali Linux**. The target systems are intentionally vulnerable machines set up for educational purposes only.

> **Disclaimer:** The techniques documented in these reports are for educational purposes only. Performing these activities against systems without explicit authorisation is illegal. Always obtain proper written permission before conducting any security testing.

## Tools Overview

| Tool | Purpose |
|------|---------|
| [Nmap](https://nmap.org/) | Network discovery and port scanning |
| [RustScan](https://github.com/RustScan/RustScan) | Fast port scanning |
| [SQLMap](https://sqlmap.org/) | Automated SQL injection detection and exploitation |
| [WPScan](https://wpscan.com/) | WordPress vulnerability scanner |
| [Kali Linux](https://www.kali.org/) | Penetration testing distribution |
